# 🍔 Imágenes de Platillos

Aquí van las FOTOS de todos los platillos del restaurante.

## ¿Qué va aquí?
- Fotos de hamburguesas
- Fotos de tacos
- Fotos de bebidas
- Fotos de postres
- Etc.

## Formato recomendado
- Formato: `.webp` (más rápido) o `.jpg` (compatible)
- Tamaño: 300x300px
- Peso: Máximo 100KB por imagen

## Ejemplo de estructura
```
/public/assets/dishes/
  ├── burger.webp
  ├── tacos.webp
  ├── salmon.webp
  ├── pasta.webp
  ├── maracuya.webp
  ├── batido-fresa.webp
  ├── cafe.webp
  ├── coctel.webp
  ├── tiramisu.webp
  ├── cheesecake.webp
  ├── brownie.webp
  └── helado.webp
```

**Nota:** Los nombres deben coincidir con lo que está en `dishes.json`

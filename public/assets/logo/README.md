# 🏷️ Logo del Restaurante

Aquí va el LOGO de "Sabor Urbano".

## ¿Qué va aquí?
- El logo del restaurante
- La imagen de marca de Sabor Urbano

## Formato recomendado
- Formato: `.svg` (vectorial, se ve bien en cualquier tamaño) o `.png` (con fondo transparente)
- Tamaño: 50x50px (para el header)
- Peso: Máximo 50KB

## Ejemplo
```
/public/assets/logo/
  └── logo.svg (o logo.png)
```

**Nota:** En App.tsx lo importarás así:
```jsx
import logo from '/public/assets/logo/logo.svg'
```
